# AVR Thermostat

James' interest in making a thermostat

# Features

- Plugs into standard residential connections
- Programmable time/day-based temperature settings
- On-board Modbus over RS-485 communication for smart home integration
- Heating, cooling, or off modes
- Battery-backed settings and time
- Support on-cool and on-heat reverse valve types
- Auto or always-on fan setting
- Display in Fahrenheit or Celsius
- ISP header for firmware flashing and updates
- Objectively gorgeous vacuum-florescent display
- Runs on a familiar, lovable AVR
- All this and more, in a small & tiny 8Kb firmware piece
